# User Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enable the OS to transition from ring 0 (kernel) to ring 3 (user mode), running a GRUB module as a user-space C program with its own page tables and stack.

**Architecture:** Add a TSS to the GDT so the CPU knows which kernel stack to use during ring transitions. Create a C-based paging module that builds per-process page directories mixing 4 MiB PSE pages (for kernel identity mapping) with 4 KiB page tables (for user-accessible regions). Build user programs as flat binaries with a C entry point via a startup stub. Use `iret` to drop from ring 0 to ring 3 with interrupts disabled (syscalls/interrupts come in a later plan).

**Tech Stack:** i686-elf-gcc, i686-elf-ld, NASM, QEMU, GDB

---

## Current State

The kernel boots via GRUB Multiboot at physical 0x00100000, sets up a flat GDT (5 entries: null, kernel code 0x08, kernel data 0x10, user code 0x18, user data 0x20), enables identity paging with 4 MiB PSE pages (supervisor-only, flags 0x83), initializes PIC+IDT (keyboard IRQ only), has a bitmap PFA and K&R heap. A GRUB module (flat binary) is called as a ring-0 function pointer. There is no TSS, no per-process page tables, no ring-3 execution.

void tss_init(unsigned int kernel_stack_top, unsigned int kernel_data_segment)
{
    memset(&tss, 0, sizeof(tss));
    tss.ss0 = kernel_data_segment;
    tss.esp0 = kernel_stack_top;
    tss.iomap_base = (unsigned short)sizeof(struct tss_entry);

void tss_load(void)
{
    __asm__ __volatile__(
        "movw $0x28, %%ax\n\t"
        "ltr %%ax"
        : : : "eax"
    );
}

void tss_set_kernel_stack(unsigned int stack_top)
{
    tss.esp0 = stack_top;
}

unsigned int tss_get_base(void)
{
    return (unsigned int)&tss;
}

unsigned int tss_get_limit(void)
{
    return (unsigned int)(sizeof(struct tss_entry) - 1U);
}

- [ ] **Step 3: Modify `src/gdt.c` — expand GDT to 6 entries, add TSS**

Replace the entire file with:

```c
#include "gdt.h"
#include "tss.h"

struct gdt_entry {
    unsigned short limit_low;
    unsigned short base_low;
    unsigned char base_middle;
    unsigned char access;
    unsigned char granularity;
    unsigned char base_high;
} __attribute__((packed));

struct gdt_ptr {
    unsigned short limit;
    unsigned int base;
} __attribute__((packed));

extern void gdt_load(struct gdt_ptr *ptr);

static struct gdt_entry gdt[6];
static struct gdt_ptr gp;

static void gdt_set_gate(int idx, unsigned int base, unsigned int limit,
                         unsigned char access, unsigned char gran)
{
    gdt[idx].base_low = (unsigned short)(base & 0xFFFFU);
    gdt[idx].base_middle = (unsigned char)((base >> 16) & 0xFFU);
    gdt[idx].base_high = (unsigned char)((base >> 24) & 0xFFU);

    gdt[idx].limit_low = (unsigned short)(limit & 0xFFFFU);
    gdt[idx].granularity = (unsigned char)((limit >> 16) & 0x0FU);
    gdt[idx].granularity |= (unsigned char)(gran & 0xF0U);
    gdt[idx].access = access;
}

void gdt_init(void)
{
    gp.limit = (unsigned short)(sizeof(gdt) - 1U);
    gp.base = (unsigned int)&gdt;

    gdt_set_gate(0, 0U, 0U, 0U, 0U);                           /* null */
    gdt_set_gate(1, 0U, 0xFFFFFFFFU, 0x9AU, 0xCFU);            /* kernel code */
    gdt_set_gate(2, 0U, 0xFFFFFFFFU, 0x92U, 0xCFU);            /* kernel data */
    gdt_set_gate(3, 0U, 0xFFFFFFFFU, 0xFAU, 0xCFU);            /* user code */
    gdt_set_gate(4, 0U, 0xFFFFFFFFU, 0xF2U, 0xCFU);            /* user data */
    gdt_set_gate(5, tss_get_base(), tss_get_limit(), 0x89U, 0x00U); /* TSS */

    gdt_load(&gp);
}
```

Key details for GDT entry 5 (TSS):
- `base` = address of the TSS struct in memory
- `limit` = sizeof(tss) - 1 = 103 = 0x67
- `access` = 0x89: Present=1, DPL=0, System segment, Type=1001 (32-bit TSS available)
- `granularity` = 0x00: byte granularity, no extra flags

### Task 3: 4 KiB Page Table Module

Create a C module that can build page directories with mixed 4 MiB PSE pages and 4 KiB page tables. This is needed because user code is mapped at virtual 0x00000000 (same 4 MiB region as the kernel at 0x00100000), so we need 4 KiB granularity to set different U/S permissions.

**Memory layout for a user process:**

```
Virtual Address          Mapping                          Permissions
0x00000000 - code_end    User code (allocated frames)     U/S=1, RW, Present
0x00100000 - kernel_end  Kernel (identity-mapped)         U/S=0, RW, Present
rest of 4 GiB            Identity-mapped (4 MiB PSE)     U/S=0, RW, Present
0xBFFFF000 - 0xBFFFFFFF  User stack (allocated frame)     U/S=1, RW, Present
```

**Key insight:** PDE 0 covers 0x00000000-0x003FFFFF. Both user code (at 0x00000000) and kernel (at 0x00100000) live here. With a 4 MiB page we can't give them different permissions. So PDE 0 must be split into a page table of 1024 × 4 KiB entries, where user PTEs have U/S=1 and kernel PTEs have U/S=0. The PDE itself must have U/S=1 (permissions are hierarchical — PDE U/S=0 blocks all user access regardless of PTE flags).

**Files:**
- Create: `include/paging4k.h`

- [ ] **Step 1: Create `include/paging4k.h`**

```c
#ifndef INCLUDE_PAGING4K_H
#define INCLUDE_PAGING4K_H

#define PTE_PRESENT  0x01U
#define PTE_RW       0x02U
#define PTE_USER     0x04U

#define PDE_PRESENT  0x01U
#define PDE_RW       0x02U
#define PDE_USER     0x04U
#define PDE_PS       0x80U

/* Allocate a new page directory with all 1024 PDEs set to 4 MiB PSE
 * identity-mapped supervisor-only pages (same as boot paging). */
unsigned int *paging_create_kernel_dir(void);

/* Map a single 4 KiB page: virtual -> physical with given flags.
 * If the PDE currently holds a 4 MiB PSE page, it is automatically split
 * into a 4 KiB page table preserving the identity mapping. */
void paging_map_4k(unsigned int *dir, unsigned int virt,
                   unsigned int phys, unsigned int flags);

/* Switch the active page directory by writing to CR3. */
void paging_switch(unsigned int dir_phys);

#endif /* INCLUDE_PAGING4K_H */
```

- [ ] **Step 2: Create `src/paging4k.c`**

```c
#include "paging4k.h"
#include "pfa.h"
#include "kutil.h"

unsigned int *paging_create_kernel_dir(void)
{
    unsigned int frame;
    unsigned int *dir;
    unsigned int i;

    frame = pfa_alloc();
    if (frame == 0U) {
        return (unsigned int *)0;
    }

    dir = (unsigned int *)frame;

    for (i = 0; i < 1024; i++) {
        dir[i] = (i << 22) | PDE_PRESENT | PDE_RW | PDE_PS;
    }

    return dir;
}

void paging_map_4k(unsigned int *dir, unsigned int virt,
                   unsigned int phys, unsigned int flags)
{
    unsigned int pde_idx = virt >> 22;
    unsigned int pte_idx = (virt >> 12) & 0x3FFU;
    unsigned int *pt;
    unsigned int pt_frame;
    unsigned int i;

    if (dir[pde_idx] & PDE_PS) {
        /*
         * Split a 4 MiB PSE page into a page table of 1024 x 4 KiB pages.
         * Each PTE identity-maps its portion of the original 4 MiB range
         * with supervisor-only permissions (matching the original PDE).
         */
        unsigned int base = dir[pde_idx] & 0xFFC00000U;

        pt_frame = pfa_alloc();
        if (pt_frame == 0U) {
            return;
        }
        pt = (unsigned int *)pt_frame;

        for (i = 0; i < 1024; i++) {
            pt[i] = (base + i * PAGE_SIZE) | PTE_PRESENT | PTE_RW;
        }

        dir[pde_idx] = pt_frame | PDE_PRESENT | PDE_RW;
        if (flags & PTE_USER) {
            dir[pde_idx] |= PDE_USER;
        }

    } else if (!(dir[pde_idx] & PDE_PRESENT)) {
        /* PDE not present — allocate a fresh zeroed page table. */
        pt_frame = pfa_alloc();
        if (pt_frame == 0U) {
            return;
        }
        pt = (unsigned int *)pt_frame;
        memset(pt, 0, PAGE_SIZE);

        dir[pde_idx] = pt_frame | PDE_PRESENT | PDE_RW;
        if (flags & PTE_USER) {
            dir[pde_idx] |= PDE_USER;
        }

    } else {
        /* PDE already points to a page table. */
        pt = (unsigned int *)(dir[pde_idx] & 0xFFFFF000U);

        if ((flags & PTE_USER) && !(dir[pde_idx] & PDE_USER)) {
            dir[pde_idx] |= PDE_USER;
        }
    }

    pt[pte_idx] = (phys & 0xFFFFF000U) | flags;
}

void paging_switch(unsigned int dir_phys)
{
    __asm__ __volatile__("mov %0, %%cr3" : : "r"(dir_phys) : "memory");
}
```

- [ ] **Step 2: Create `src/usermode.s`**

```nasm
; enter_usermode: switch page directory, set user segments, iret to ring 3
;
; void enter_usermode(unsigned int eip, unsigned int esp_user,
;                     unsigned int page_dir_phys)
;
; Segment selectors with RPL=3:
;   User code: GDT index 3 -> 0x18 | 0x03 = 0x1B
;   User data: GDT index 4 -> 0x20 | 0x03 = 0x23

global enter_usermode

enter_usermode:
    mov eax, [esp + 12]         ; page_dir_phys
    mov cr3, eax                ; switch to user page directory

    mov ax, 0x23                ; user data selector (0x20 | RPL 3)
    mov ds, ax
    mov es, ax
    mov fs, ax
    mov gs, ax

    mov eax, [esp + 4]          ; eip  (user entry point)
    mov ebx, [esp + 8]          ; esp_user (user stack top)

    push dword 0x23             ; ss:  user data selector
    push ebx                    ; esp: user stack pointer
    push dword 0x0002           ; eflags: IF=0 (interrupts disabled), bit 1 reserved
    push dword 0x1B             ; cs:  user code selector (0x18 | RPL 3)
    push eax                    ; eip: user entry point

    iret
```

How this works:
1. Switch CR3 to the user page directory (kernel is still identity-mapped, so we keep executing).
2. Load all data segment registers with the user data selector (RPL=3).
3. Push an inter-privilege `iret` frame: SS, ESP, EFLAGS, CS, EIP.
4. `iret` pops these values, causing the CPU to transition to ring 3 at the user's EIP/ESP.

EFLAGS = 0x0002: bit 1 is always set (reserved), IF=0 disables hardware interrupts. We keep interrupts disabled for now — enabling them requires proper syscall handling (covered in the next plan).

- [ ] **Step 4: Modify `src/kmain.c` — set up user address space and enter user mode**

Replace the entire file with:

```c
#include "gdt.h"
#include "tss.h"
#include "idt.h"
#include "fb.h"
#include "kheap.h"
#include "kutil.h"
#include "multiboot.h"
#include "paging.h"
#include "paging4k.h"
#include "pfa.h"
#include "serial.h"
#include "usermode.h"

extern char kernel_stack[];
#define KERNEL_STACK_SIZE 4096U

#define USER_CODE_VIRT  0x00000000U
#define USER_STACK_VIRT 0xBFFFF000U
#define USER_STACK_TOP  0xC0000000U

void kmain(unsigned int multiboot_magic,
           unsigned int multiboot_info_addr,
           unsigned int kernel_physical_start,
           unsigned int kernel_physical_end)
{
    multiboot_info_t *mbinfo = (multiboot_info_t *)multiboot_info_addr;
    multiboot_module_t *mod;
    unsigned int mod_size;
    unsigned int code_pages;
    unsigned int *user_dir;
    unsigned int stack_frame;
    unsigned int code_frame;
    unsigned int offset;
    unsigned int copy_len;
    unsigned int i;

    tss_init((unsigned int)kernel_stack + KERNEL_STACK_SIZE, 0x10);
    gdt_init();
    tss_load();
    paging_enable_identity();

    serial_init(SERIAL_COM1_BASE);
    fb_clear();
    idt_init();

    if (multiboot_magic != MULTIBOOT_BOOTLOADER_MAGIC) {
        fb_write("Invalid multiboot magic\n", 24);
        serial_write(SERIAL_COM1_BASE, "Invalid multiboot magic\n", 24);
        while (1)
            ;
    }

    pfa_init(multiboot_info_addr, kernel_physical_start, kernel_physical_end);
    kheap_init();

    if (!(mbinfo->flags & MULTIBOOT_INFO_MODS) || mbinfo->mods_count < 1) {
        fb_write("ERROR: No module from GRUB.\n", 28);
        goto halt;
    }

    mod = (multiboot_module_t *)mbinfo->mods_addr;
    mod_size = mod->mod_end - mod->mod_start;
    code_pages = (mod_size + PAGE_SIZE - 1U) / PAGE_SIZE;

    /* Reserve module memory so PFA doesn't hand out overlapping frames. */
    pfa_reserve(mod->mod_start, mod->mod_end);

    /* Create a page directory: identity-mapped kernel (4 MiB PSE, supervisor). */
    user_dir = paging_create_kernel_dir();
    if (user_dir == (unsigned int *)0) {
        fb_write("ERROR: Cannot alloc page dir.\n", 30);
        goto halt;
    }

    /* Allocate frames for user code, copy module binary, map at virtual 0. */
    for (i = 0; i < code_pages; i++) {
        code_frame = pfa_alloc();
        if (code_frame == 0U) {
            fb_write("ERROR: Cannot alloc code frame.\n", 32);
            goto halt;
        }
        offset = i * PAGE_SIZE;
        copy_len = mod_size - offset;
        if (copy_len > PAGE_SIZE) {
            copy_len = PAGE_SIZE;
        }
        memcpy((void *)code_frame, (void *)(mod->mod_start + offset), copy_len);
        if (copy_len < PAGE_SIZE) {
            memset((void *)(code_frame + copy_len), 0, PAGE_SIZE - copy_len);
        }
        paging_map_4k(user_dir, USER_CODE_VIRT + offset, code_frame,
                       PTE_PRESENT | PTE_RW | PTE_USER);
    }

    /* Allocate one frame for user stack, map at 0xBFFFF000. */
    stack_frame = pfa_alloc();
    if (stack_frame == 0U) {
        fb_write("ERROR: Cannot alloc stack.\n", 27);
        goto halt;
    }
    memset((void *)stack_frame, 0, PAGE_SIZE);
    paging_map_4k(user_dir, USER_STACK_VIRT, stack_frame,
                   PTE_PRESENT | PTE_RW | PTE_USER);

    fb_write("Entering user mode...\n", 22);

    /* Point of no return: switch page directory, iret to ring 3. */
    enter_usermode(USER_CODE_VIRT, USER_STACK_TOP, (unsigned int)user_dir);

halt:
    while (1) {
        __asm__ __volatile__("hlt");
    }
}
```

## Summary of Verification

After all tasks are complete, the boot sequence is:

1. GRUB loads `kernel.elf` and the `program` module
2. `loader.s` sets up the stack, calls `kmain`
3. `kmain` initializes: TSS → GDT (with TSS entry) → load TR → paging → serial → VGA → IDT
4. PFA and heap initialized
5. Module's physical memory reserved in PFA
6. A new page directory is created (identity-mapped kernel, 4 MiB PSE)
7. User code frames allocated, module copied, mapped at virtual 0x00000000 with U/S=1
8. User stack frame allocated, mapped at 0xBFFFF000 with U/S=1
9. `enter_usermode`: switch CR3, set user segments, push iret frame, `iret` → ring 3
10. User program executes `_start` → `call main` → `while(1){}`

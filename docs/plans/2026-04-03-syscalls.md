# System Calls Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement system calls via `int 0x80` so user-mode programs can request kernel services (write to screen, exit process).

**Architecture:** User programs invoke `int 0x80` with the syscall number in `eax` and arguments in `ebx`/`ecx`/`edx`. The CPU switches to the kernel stack (via TSS), and a dedicated assembly handler saves registers and calls a C dispatcher. The dispatcher reads the syscall number, executes the appropriate kernel function, and stores the return value in the saved `eax`. On return, `iret` restores user mode. Interrupts are enabled in user mode so `int 0x80` works.

**Tech Stack:** i686-elf-gcc, NASM, QEMU

---

## Syscall Convention

| Register | Purpose |
|----------|---------|
| `eax` | Syscall number (in) / return value (out) |
| `ebx` | Argument 1 |
| `ecx` | Argument 2 |
| `edx` | Argument 3 |

| Number | Name | Args | Description |
|--------|------|------|-------------|
| 1 | `SYS_WRITE` | ebx=buf, ecx=len | Write string to framebuffer |
| 2 | `SYS_EXIT` | — | Terminate process |

### Task 2: Syscall Assembly Handler

**Files:**
- Create: `src/syscall_handler.s`

- [ ] **Step 1: Create `src/syscall_handler.s`**

```nasm
; syscall_handler.s — int 0x80 entry point
;
; When int 0x80 fires from ring 3:
;   1. CPU switches to kernel stack (SS0:ESP0 from TSS)
;   2. CPU pushes: SS_user, ESP_user, EFLAGS, CS, EIP
;   3. We save GP registers, call C dispatcher with pointer to saved state
;   4. C dispatcher reads EAX (syscall number), may modify EAX (return value)
;   5. We restore GP registers and IRET back to ring 3

global syscall_handler_128
extern syscall_dispatch

syscall_handler_128:
    push eax
    push ebx
    push ecx
    push edx
    push esi
    push edi
    push ebp

    push esp                    ; arg: pointer to saved registers
    call syscall_dispatch
    add esp, 4

    pop ebp
    pop edi
    pop esi
    pop edx
    pop ecx
    pop ebx
    pop eax

    iret
```

Add to Makefile temporarily or just assemble:

Run: `nasm -f elf32 src/syscall_handler.s -o build/syscall_handler.o`

- [ ] **Step 1: Create `include/syscall.h`**

```c
#ifndef INCLUDE_SYSCALL_H
#define INCLUDE_SYSCALL_H

#define SYS_WRITE 1
#define SYS_EXIT  2

struct syscall_regs {
    unsigned int ebp;
    unsigned int edi;
    unsigned int esi;
    unsigned int edx;
    unsigned int ecx;
    unsigned int ebx;
    unsigned int eax;
};

void syscall_dispatch(struct syscall_regs *regs);

#endif /* INCLUDE_SYSCALL_H */
```

- [ ] **Step 2: Create `src/syscall.c`**

```c
#include "syscall.h"
#include "fb.h"

void syscall_dispatch(struct syscall_regs *regs)
{
    switch (regs->eax) {
    case SYS_WRITE:
        regs->eax = (unsigned int)fb_write((const char *)regs->ebx, regs->ecx);
        break;
    case SYS_EXIT:
        while (1) {
            __asm__ __volatile__("hlt");
        }
        break;
    default:
        regs->eax = (unsigned int)-1;
        break;
    }
}
```

### Task 6: User-Mode Syscall Library and Test Program

**Files:**

- [ ] **Step 1: Create `programs/syscall.h`**

```c
#ifndef PROGRAMS_SYSCALL_H
#define PROGRAMS_SYSCALL_H

#define SYS_WRITE 1
#define SYS_EXIT  2

static inline int write(const char *buf, unsigned int len)
{
    int ret;
    __asm__ __volatile__(
        "int $0x80"
        : "=a"(ret)
        : "a"(SYS_WRITE), "b"(buf), "c"(len)
        : "memory"
    );
    return ret;
}

static inline void exit(void)
{
    __asm__ __volatile__(
        "int $0x80"
        :
        : "a"(SYS_EXIT)
    );
    while (1) {}
}

#endif /* PROGRAMS_SYSCALL_H */
```

## Verification

The boot sequence with syscalls:

1. GRUB loads kernel + initrd
2. Kernel initializes (GDT, TSS, IDT with int 0x80 at DPL=3, PIC, PFA, heap, filesystem)
3. Kernel enters user mode with IF=1 (interrupts enabled)
4. User program executes `int 0x80` with eax=SYS_WRITE
5. CPU switches to kernel stack (TSS), jumps to syscall_handler_128
6. Assembly saves registers, calls syscall_dispatch
7. Dispatcher calls fb_write, stores return value in saved eax
8. Assembly restores registers, iret back to ring 3
9. User program executes `int 0x80` with eax=SYS_EXIT
10. Dispatcher halts the CPU
